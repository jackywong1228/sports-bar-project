# 小程序审核整改说明

**小程序**：云立方运动空间（用户端）
**AppID**：wxa780255d50dfbf1e
**整改日期**：2026-08-07
**对应驳回原因**：小程序服务内提供虚拟产品、虚拟商品购买服务，其购买和支付均需接入官方「小程序虚拟支付」能力

---

## 一、业务性质说明

本小程序为**线下体育场馆（运动空间）的预约服务工具**，面向到店会员提供：

- 场馆场地预约（线下实体服务消费）
- 教练课程预约（线下实体服务消费）
- 会员到店服务（会员码、训练日历、活动报名等）

小程序内的线上支付**仅用于场馆/教练等线下实体服务的预约消费**。

## 二、整改措施

针对驳回意见，本次版本已**完整移除小程序内全部虚拟商品在线购买功能**，具体如下：

### 1. 金币（到店储值余额）充值入口已移除

- 金币为本店会员**到店储值**的消费余额，仅支持**门店前台线下充值**，小程序内不提供、也不宣传在线充值
- 已移除位置：「我的」页资产区充值入口、「钱包」页充值按钮、教练钱包页充值按钮
- 原充值页已改造为纯说明页（仅告知"请前往门店前台办理"及金币使用规则），页面内无任何套餐、价格档位与支付功能

### 2. 会员卡在线购买已移除

- 会员中心页仅作会员**权益展示**；点击会员套餐卡片改为提示"会员开通与续费请前往门店前台办理"，不再创建订单、不再拉起支付
- 会员开通/续费均为到店线下办理

### 3. 保留的支付场景（均为线下实体服务，合规）

- **场馆预约微信支付**：用户预约场地时段时支付的场地费用，属线下实体服务消费
- **金币余额支付**：消耗到店储值余额用于场馆预约，属储值卡线下消费的线上核销，非虚拟商品购买

### 4. 其他说明

- 积分商城：积分仅通过签到、活动等**免费方式获得**，用于兑换店内商品，无任何积分售卖
- 邀请赠币：金币仅作为到店活动的免费奖励发放，不可购买
- 全包代码自查：当前版本调用 `wx.requestPayment` 的页面仅剩 3 个（场馆预约、订单列表补支付、订单详情补支付），全部为场地预约这一线下实体服务的支付场景
